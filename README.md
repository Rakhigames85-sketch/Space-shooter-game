
# Space Shooter Game 🚀

Python Turtle module se bana simple arcade game. Ship ko Left/Right arrow se move karo, Space dabake asteroid tod do 💥

### Features
- **Dynamic Difficulty**: Score badhega `3 + score/50` formula se speed bhi badhegi
- **Score System**: Har asteroid pe +10 points 
- **Game Over Screen**: Ship touch hote hi clean Game Over screen + Final Score
- **Collision Detection**: Goli aur asteroid ka touch check

### Controls
| Key | Kaam |
| --- | --- |
| Left Arrow | Left move |
| Right Arrow | Right move |
| Space | Fire bullet |

### Kaise Chalaye
Terminal me run karo: 
`python space_shooter.py`
